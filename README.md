# Supply Chain Delivery Performance and Profitability Analytics

## 📌 Project Overview

This project focuses on analyzing supply chain operations, delivery performance, sales, and profitability using Microsoft Power BI.

The main objective is to transform raw data into meaningful business insights through interactive dashboards and data visualizations.

## 🎯 Project Objectives

- Analyze overall sales and revenue performance.
- Evaluate profitability across different markets.
- Monitor delivery performance and order trends.
- Understand customer segment performance.
- Identify business trends and patterns to support better decision-making.

## 🛠️ Tools & Technologies

- **Power BI** – Dashboard development and data visualization
- **Power Query** – Data cleaning and transformation
- **DAX** – Measures and calculated metrics
- **Data Modeling** – Organizing data for effective analysis

## 📊 Dashboard Features

This project contains six interactive dashboard pages covering:

- Sales and Revenue Analysis
- Profitability Analysis
- Delivery Performance
- Market-wise Performance
- Customer Segment Analysis
- Overall Business Performance

## 🔍 Key Analytical Areas

- Total Revenue
- Revenue Growth Percentage
- Revenue per Customer
- Total Profit
- Delivery
